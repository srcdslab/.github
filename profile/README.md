# NiDE · SRCDSLab

SRCDSLab is the open-source development space of [NiDE.GG](https://nide.gg), a gaming community focused on Counter-Strike: Source and Zombie Escape.

Here you'll find SourceMod plugins, Source engine tools, server utilities, and community projects maintained by the NiDE team and contributors. Some repositories are forks of upstream projects that we use and improve; their original authors retain credit in each repository.

## Get involved

Browse the repositories, open an issue to report a problem or suggest an improvement, and submit a pull request if you'd like to contribute.

**Community:** [nide.gg](https://nide.gg) · [Discord](https://discord.gg/EFbtjSUUxG)
