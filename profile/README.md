## 🎮 Welcome to the workshop

NiDE.GG is a gaming community with a focus on **Counter-Strike: Source** and **Zombie Escape**. SRCDSLab is where our team and contributors build, maintain, and share the code that helps keep Source engine servers running and evolving.

Expect SourcePawn plugins, C++ extensions, Python tools, experiments, and the occasional fix for a problem only a game server admin would understand.

## 🤝 Join the party

1. Pick a repository and read its README and contribution notes.
2. Found a bug or have an idea? Open an issue in that repository.
3. Have a fix? Send a pull request with a clear description and a way to test it.

A number of projects here are forks. We credit upstream authors in their repositories and welcome improvements that benefit the wider SourceMod community.
